The leader is the one replica that runs the jobs that must happen only once (threat-feed and country downloads, rule-set checks, auto-ban, flood escalation, spike alerts). If it stops, another replica takes over within a few seconds.

How configuration changes reach all replicas

Saving a change applies it on the replica you are connected to, stores it in the database, and every other replica applies it by itself within about a second. The confirmation message tells you how many replicas have applied it.
